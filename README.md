# Rutbygget

En svensk, enkel React/Vite-webbplats som visar multiplikation visuellt.

Barnet klickar på en ruta i rutnätet. Då fylls en rektangel från övre vänstra hörnet till den valda rutan.

Exempel:

- Klick på rad 3, kolumn 4 visar `3 × 4 = 12`
- Rektangeln visar rader × kolumner
- Upprepad addition visas under rutnätet

## Kör lokalt

```bash
npm install
npm run dev
```

Öppna sedan Vite-adressen som visas i terminalen.

## Bygg

```bash
npm run build
```
